# Security Policy

Bims City Atlas is a public-data project. Do not add secrets, API tokens,
private datasets, personal contact data, unpublished records, or confidential
planning material to this repository.

## Reporting A Vulnerability

If GitHub private vulnerability reporting is enabled, use it. Otherwise contact
the maintainers out of band before opening a public issue for anything that
could expose secrets, private data, or a deployment weakness.

For ordinary data-quality problems, use the data-correction issue template.

## Maintainer Expectations

- Rotate any credential that appears in an issue, pull request, log, screenshot,
  fixture, or generated artifact.
- Remove private or sensitive data from publication paths.
- Treat source licences and privacy caveats as release blockers.
- Keep retired simulation or proof-flow paths quarantined from public runtime
  routes.
